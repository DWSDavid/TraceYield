## 一、一句话总纲 (The whole project in one sentence)

> **预测美联储 (the Fed) 和宏观环境 → 预测 10年期美债收益率 (10Y Treasury yield) 的方向 → 因为几乎所有资产都按它定价,所以等于预测了半个金融市场。**

整个 TraceYield 就是在量化这一条链。

## 二、最最核心的一条铁律 (The one rule you must never flip)

### 价格 (Price) 和 收益率 (Yield) 永远反向

```
Yield ↑   ⟺   Price ↓     债券熊市 (Bond Bear)
Yield ↓   ⟺   Price ↑     债券牛市 (Bond Bull)
```

**为什么?** 债券的利息(票息 coupon)是**固定**的。假设你手里的债券每年付 4%:
- 市场新债开始付 5% 了 → 没人要你这张只付 4% 的 → 你只能**降价**卖 → 你这张债的"实际收益率"被买家压到 5% 才有人接。
- **所以新利率涨上去,旧债价格就得跌下来。** 这是数学,不是情绪。

> 记忆口诀:**"收益率和价格是跷跷板"** (yield and price are a seesaw)。
> 本项目说 **"Bear / 看空债"** = 预测 **yield 涨、price 跌**。
> 说 **"Bull / 看多债"** = 预测 **yield 跌、price 涨**。

⚠️ 90% 的新手错误都来自把这条记反。**先把它焊死在脑子里。**

## 三、什么会推动 10Y?六条因果链 (The 6 causal chains)

每条链最后都归到一个方向:**推 yield 往上 (↑) 还是往下 (↓)**。
正向(往上)= 利空债券 = 本项目里因子分为**正**。

### 链 1:通胀 (Inflation) ↑ → Yield ↑
```
通胀上升 → ① 出借人要求补偿被侵蚀的购买力(费雪效应 Fisher effect)
         → ② 美联储很可能加息压通胀 → 预期政策利率路径上移
         → 两条都把 yield 顶上去
```
- 公式直觉:**名义收益率 (nominal yield) ≈ 实际收益率 (real yield) + 预期通胀 (expected inflation)**。通胀预期一升,名义 yield 就升。
- 这就是你报告里 `inflation` 因子为**正(+0.37)**时在说的事:通胀在推利率上行。
- 对应代码:[factors.py](../../src/signals/factors.py) 的 `inflation_factor`(看核心PCE + 通胀保值债隐含的 breakeven)。

> **Breakeven inflation(盈亏平衡通胀)** = 普通国债收益率 − 通胀保值债(TIPS)收益率,
> = 市场**当下定价**的未来通胀。它升 = 市场认为通胀要起来 = yield 上行压力。

### 链 2:美联储鹰派 (Hawkish Fed) → Yield ↑
```
美联储偏鹰(担心通胀、倾向收紧)→ 预期未来政策利率更高 → yield ↑(尤其短端)
美联储偏鸽(担心增长/就业、倾向宽松)→ 预期降息 → yield ↓
```
- **鹰派 Hawkish 🦅 = 收紧 = yield 涨**;**鸽派 Dovish 🕊️ = 宽松 = yield 跌**。
- 这是本项目**权重最高(30%)**的因子 `fomc_nlp`:我们用 GPT 读 FOMC 文件,打一个 [-1 鸽, +1 鹰] 的分。
- 细节看 [01-fomc-and-the-fed.md](01-fomc-and-the-fed.md)。

### 链 3:流动性 (Liquidity) 收紧 → Yield ↑
```
QE(量化宽松):美联储买债 → 债价被买高 → yield ↓
QT(量化紧缩):美联储缩表/放任债券到期 → 少了一个大买家 + 市场要消化更多债 → yield ↑
准备金/RRP 充裕 → 钱多 → 压低 yield;枯竭 → 资金紧张 → 推高 yield
```
- 你报告里 `liquidity` 因子为**负(-0.41)**,意思是"当前流动性偏宽松,在往下拉 yield"。
- 对应 `liquidity_factor`(看美联储总资产 WALCL、银行准备金 WRESBAL 的变化)。

### 链 4:经济增长 (Growth) 强 → Yield ↑
```
增长强劲 → ① 企业/个人抢着借钱投资消费 → 资金需求大 → 利率↑
         → ② 美联储可能收紧防过热 → yield ↑
         → ③ 没人需要避险 → 资金从债市流出 → 价格↓ yield↑
衰退担忧 → 反过来:避险 + 预期降息 → yield ↓
```

### 链 5:避险情绪 (Safe-haven / Risk-off) → Yield ↓
```
打仗、股灾、危机 → 资金涌入"最安全资产"美债 → 债价被买高 → yield ↓
```
- 美债是全球**避险天堂 (safe-haven)**。所以"坏消息"有时反而让 yield 跌(钱跑来买债)。
- 这就是为什么**同样 yield 下跌,原因不同含义完全相反**(见第六节)。

### 链 6:供给/财政 (Supply / Fiscal) ↑ → Yield ↑
```
政府发债越多(赤字大)→ 市场要消化的债券供给↑ → 价格↓ yield↑
期限溢价 (term premium) 上升 → 持有长债的额外补偿↑ → 长端 yield↑
```
- **期限溢价 Term Premium** = 你愿意持有 10 年长债(而不是不断滚动短债)所要求的额外利息。它受供给、不确定性影响,**不全是美联储说了算**——这是 v0 系统目前覆盖不足、v1 要补的(P3.3)。

> ### 把 10Y 拆开看(最重要的分解 The key decomposition)
> ```
> 10Y 名义收益率  ≈  未来十年预期短期利率的平均   (← 美联储路径,链2)
>                 +  期限溢价 term premium          (← 供给/风险,链6)
>
> 又可写成:     ≈  实际收益率 real yield          (← 增长,链4)
>                 +  盈亏平衡通胀 breakeven         (← 通胀,链1)
> ```
> **读报告时永远先问:这次 yield 动,是哪一块在动?** 是通胀预期?还是期限溢价?
> 还是美联储路径?原因不同,跨资产影响完全不同。

## 四、五大因子 = 上面六条链的工程化 (Factors = the chains, in code)

本项目把这些链压缩成 **5 个因子**,每个归一化到 [-1, +1],**正 = 推 yield 上行 = 利空债**:

| 因子 (Factor) | 对应哪条链 | 权重 | 正分含义 |
|---|---|---|---|
| `fomc_nlp` | 链2 美联储 | 30% | 美联储偏鹰 → yield↑ |
| `inflation` | 链1 通胀 | 25% | 通胀升温 → yield↑ |
| `liquidity` | 链3 流动性 | 20% | 流动性收紧 → yield↑ |
| `global_rates` | 全球利差 | 15% | 美债相对更有吸引力/资金流向 |
| `political_risk` | 链5/6 风险 | 10% | 政治/地缘风险溢价 |

**怎么算的(因子分 = z-score 标准分):** 不是看绝对水平,而是看**"现在偏离过去一年的常态多少个标准差"**。
```
z = (今天的值 − 过去252天均值) / 过去252天标准差,再压到 [-1, 1]
```
因为市场交易的是**"超出预期的变化"**,不是水平本身。
(这也是 v1 要加 **macro surprise 层**的原因:真正驱动当日行情的是"实际数据 vs 市场预期",P3.2。)

**综合预测 = 各因子分 × 权重,再加总:**
```
综合分 = Σ (权重ᵢ × 因子分ᵢ)
综合分 > +0.15 → 看空债 (Bear, yield↑)
综合分 < −0.15 → 看多债 (Bull, yield↓)
中间          → 中性 (Neutral)
```
(那个 ±0.15 是我**拍脑袋**的先验值,回测已证明目前没校准好——见第七节。)

## 五、收益率曲线 (The Yield Curve) —— 不止一个点,是一条线

把不同期限(2Y、5Y、10Y、30Y)的 yield 连起来 = **收益率曲线 (yield curve)**。它的**形状**讲故事:

```
短端 (short end, 2Y) ← 主要由"美联储政策预期"决定
长端 (long end, 30Y) ← 主要由"增长 + 通胀 + 期限溢价"决定
```

**关键利差 (key spreads):**
- **2s10s** = 10Y − 2Y。本项目要预测它(P2.4)。
- **5s30s** = 30Y − 5Y。

**四种典型形变 (4 curve moves)** —— 这是 v1 让 Neutral 变有用的关键:
| 名称 (bilingual) | 谁动得快 | 典型原因 |
|---|---|---|
| 牛市陡峭化 Bull Steepener | 短端跌得快 | 美联储要降息(链2鸽) |
| 熊市陡峭化 Bear Steepener | 长端涨得快 | 财政/通胀/期限溢价(链1、6) |
| 牛市平坦化 Bull Flattener | 长端跌得快 | 避险、衰退担忧(链5) |
| 熊市平坦化 Bear Flattener | 短端涨得快 | 美联储加息进强经济(链2鹰+链4) |

> **曲线倒挂 (Inversion):2s10s < 0**(短端比长端还高)= 市场预期美联储很快要降息救场
> = **历史上最可靠的衰退预警信号** (most reliable recession signal)。

**为什么这对你重要:** 有时 10Y 本身几乎不动(→ Neutral),但**曲线在陡峭化或平坦化**,真正的交易机会在曲线上。这正是 v0 漏掉、v1 要补的。

## 六、跨资产连锁 (The Chain Reaction) —— 为什么预测 10Y 这么值钱

10Y 是全世界的"无风险利率基准 (risk-free benchmark)",所有资产都按它折现。**10Y 涨**时(反过来就是跌):

```
            10Y Yield ↑
   ┌──────────┬──────────┬──────────┬───────────┐
   ▼          ▼          ▼          ▼           ▼
 美元↑      股票↓      黄金↓      信用债↓     新兴市场↓
 USD up    Stocks    Gold      Credit       EM stress
 (高息吸     down      down      spreads      资金回流美元
  引资金)   (折现率高   (无息资产   widen        本币贬值
            压估值)    吸引力降)   (借贷成本↑)   美元债更贵)
```

> **关键纽带:为什么 yield 动,决定了反应方向**
> - **"好的"上涨**(增长强,链4)→ 股票能扛住,周期股甚至涨。
> - **"坏的"上涨**(通胀失控/供给过剩,链1、6)→ **股债双杀**,黄金可能反而涨(抗通胀)。
> - **鸽派降息式下跌**(软着陆)→ 万物齐涨(risk-on)。
> - **衰退恐慌式下跌**(链5)→ 债涨、股跌、黄金涨。
>
> 所以本项目坚持:**输出必须带"原因/叙事",不能只给一个方向数字。** 这就是我们让 GPT
> 给 FOMC 打分时**必须附原文引述 (key quotes)** 的理由——可信度来自"为什么",不是数字本身。

## 七、为什么报告"老是 Neutral"?(用逻辑解释 v0 的短板)

今天的真实情况:
```
inflation  +0.37  →  通胀在推 yield ↑(链1,看空债)
liquidity  −0.41  →  流动性在拉 yield ↓(链3,看多债)
两股力量几乎一样大、方向相反 → 互相抵消 → 综合分 ≈ 0 → Neutral
```

**这不是 bug,是真实的"拉锯 (tug-of-war)"** —— 当前美国宏观就是"通胀粘性 vs 流动性宽松"在对打。
但 v0 的毛病是:**它只会说 "Neutral",没告诉你"谁在跟谁打、哪个事件会打破平衡、曲线上有没有机会"。**

v1 的升级(已写进 [docs/SPEC_v1.md](../SPEC_v1.md))就是要把 Neutral 变成有用的状态:
```
不再只说:  Neutral
而是说:    Neutral —— 通胀(+0.37)对抗流动性(−0.41),冲突指数高
           方向信心低,但曲线信号活跃
           关注触发:10Y 收盘 > 4.50% 转看空;CPI 数据(6/12)可能打破平衡
```

## 八、方向速查表 (Cheat Sheet) —— 贴在脑子里

```
价格 vs 收益率:      yield ↑ = price ↓ = 看空债 Bear    (永远反向!)

推 yield 往上 ↑ (利空债 Bear):
  通胀↑  Inflation up
  鹰派   Hawkish Fed
  缩表   QT / 流动性收紧
  增长强 Strong growth
  发债多 More supply / 财政赤字↑ / 期限溢价↑

推 yield 往下 ↓ (利多债 Bull):
  通胀↓  Disinflation
  鸽派   Dovish Fed
  放水   QE / 流动性宽松
  衰退/避险 Recession fear / Risk-off (买美债避险)

曲线:  短端看美联储,长端看增长+通胀+期限溢价
       倒挂 (2s10s<0) = 衰退预警
       本项目因子:正分=推yield↑=利空债;综合分=Σ(权重×因子分)
```
